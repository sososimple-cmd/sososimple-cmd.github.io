# Sophia Mitchell — GitHub Pages Portfolio

A responsive cybersecurity project portfolio for recruiters and hiring managers.

## Publish it to your username.github.io domain

1. Sign in to GitHub as **sososimple-cmd**.
2. Create a **public** repository named exactly `sososimple-cmd.github.io` (do not initialize with README).
3. Unzip this download. On the new repository page click **uploading an existing file** (or **Add file → Upload files**).
4. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, `preview.svg` and `README.md` **directly into the repository root**, not inside an extra folder. Commit changes.
5. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**; choose `main` and `/ (root)`; save.
6. Visit **https://sososimple-cmd.github.io/** after GitHub Pages publishes it.
7. Add the published URL to LinkedIn **Contact info → Website** and your **Featured** section.

If a repository called `sososimple-cmd.github.io` already exists, upload or replace these files in that repository instead of creating a duplicate.

## Editing

- `index.html`: text, project descriptions, certification list, external links.
- `styles.css`: colors, spacing, mobile layout, typography.
- `script.js`: mobile menu and dynamic copyright year.
- `preview.svg`: sharing-card image. Some social platforms do not support SVG social previews; replace with a PNG and update the `og:image` meta tag if needed.

No framework or build tools are required. The visual console is a stylized illustration of security workflow, **not live telemetry**. No contact form or analytics collects user data.

## Local preview

Double-click `index.html`, or run `python -m http.server 8000` from the folder and visit `http://localhost:8000`.
